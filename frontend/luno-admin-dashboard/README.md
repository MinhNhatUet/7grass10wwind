# LUNO Admin Dashboard

A responsive HTML/CSS/JavaScript recreation of the supplied LUNO Admin dashboard recording.

Includes:
- Sidebar navigation
- Top search/navigation bar
- KPI cards
- Revenue stacked-bar chart
- Sales-by-category donut chart
- Welcome/documentation card
- Date-range picker interaction
- Responsive mobile layout
- Fixed Support button

Run:

```bash
python -m http.server 5500
```

Open http://localhost:5500
