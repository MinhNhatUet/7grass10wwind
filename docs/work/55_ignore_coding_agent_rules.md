# D-55 — Bỏ qua file quy định agent cục bộ

## Công việc
- Đọc đầy đủ file người dùng cung cấp tại `docs/coding_agent_rules.md`.
- Thêm `docs/coding_agent_rules.md` vào `.gitignore`; giữ nguyên mục `docs/rules/` đã có.
- Không sửa nội dung rules, không thay đổi code hay staging hiện có.

## Kiểm tra
- Dùng `git check-ignore -v` để xác nhận file rules được bỏ qua.
- Chưa commit/push/pull trong bước này.
